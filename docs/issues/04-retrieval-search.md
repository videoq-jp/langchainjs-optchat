# [P2] 元履歴検索からOptChat自身のzoom／searchの呼び出しと結果を除外する

## 問題

`src/core/memory.ts:copiesMemory()`は`/^(zoom|search)[ :]/`で元実装のログを識別するが、移植側はJSON形式と`optchat_zoom`／`optchat_search`という名前を使う。このためOptChat自身の履歴参照が除外されない。

## 再現

`name: 'optchat_zoom'`とtool_call_idを持つToolMessageに固有文字列`UNIQUE_TOKEN`を入れて記録する。その文字列で`memory.search()`すると、コピーに当たる当該ToolMessageがヒットすることを確認した。

## 影響

同じ原文を開くたびにコピーが検索対象へ蓄積し、検索結果が重複する。検索結果の再検索にもなり、原本へ到達しにくくなる。画像入力除外にも同じ識別が使われているため、共通の識別規則を検討する。
